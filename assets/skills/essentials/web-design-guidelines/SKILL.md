# Web Interface Guidelines

Review files for compliance with the Web Interface Guidelines.

## How it works

1. Read the files the user named, or ask which files or pattern to review.
2. Read `references/guidelines.md` next to this file. It holds every rule and the output format.
3. Check each file against all of the rules.
4. Report findings in the terse `file:line` format the guidelines specify.

The guidelines ship with this skill at a pinned version. Do not look for newer rules elsewhere.
