- Renamed from `ui-craft` to `agemon-design` for agemon branding — installed skills should read as agemon's own, not a third-party project name.
- Removed the commands, tools and agents agemon does not ship and routed their intents to the eight `/agemon-design <action>` passes in `references/actions.md` (`brief`, `tokens`, `build`, `review`, `polish`, `harden`, `audit`, `animate`; plain words route the same way). The 16 other upstream commands (`start`, `sddesign`, `shape`, `finalize`, `remember`, `unhappy`, `adapt`, `typeset`, `colorize`, `clarify`, `delight`, `distill`, `extract`, `redesign`, `bolder`, `quieter`) are not shipped; each routing-table row that named one now points at the matching reference file, or was removed.
- Added `references/actions.md`, adapted from upstream `commands/` at the commit above: `brief`, `tokens`, `craft` (as `build`), `critique` and `heuristic` (together as `review`), `polish`, `harden`, `audit`, `animate`. Removed from the port: the instruction to load the skill, MCP and browser-tool calls (visual capture is now phrased as a capability), the `fold_candidates` and `check_fold` tools, the aggregate UsabilityScore and UICraftScore, and `ui-craft-detect`.
- In `SKILL.md`: renamed the `# UI Craft` heading and self-references to `agemon-design`; replaced the four-rung Ladder with three rungs; removed the `route_task` MCP step, the review-agent dispatch row, the `ui-craft install` hint and the broken link to `examples/animation-storyboard.md`; updated `argument-hint` to list all eight actions.
- Deleted `references/agents.md`, which described review agents (`design-reviewer`, `a11y-auditor`) that agemon does not ship.
- Removed the UsabilityScore and Extended quality report sections from `references/heuristics.md`; replaced the `fold_candidates` and `check_fold` steps in `references/recipe-landing.md` with picking a fold class the brief has not used and comparing the render by eye; renamed `/ui-craft:` and upstream command mentions in the other references.
- Removed every model-judged numeric score and pass/fail verdict: the 1-5 per-heuristic ratings, the PASS/FAIL design-law audit, the scorecard and "machine-parseable" output in `references/heuristics.md` and `references/actions.md`, the persona `Pass/Fail` column, and the `Anti-Slop Verdict` pass/fail in `references/review.md`. Heuristic reviews now list severity-ranked findings that each name an element and a viewport; the heuristics and laws remain as a checklist. Numeric facts (contrast ratios, target sizes, durations) are unchanged.
- Replaced guidance that steered toward common generated looks: in `SKILL.md`, "Inter/Geist/DM Sans are safe fallbacks" now says to use the project's fonts or choose from the brief and say why, and "90%+ neutral, one accent" is one palette option, not the default; in `references/craft-intent.md`, the three Craft Read examples and the italic-emphasis line were replaced with subject-derived ones; in `references/themes.md`, Graphite is no longer the default, Porcelain's accent moved from terracotta to teal, Carbon's from mint to sky blue, and Signal and Graphite carry a note on the looks they sit near; the three surface recipes no longer default to Graphite, and the dashboard and auth signature-bet examples no longer name a metric sparkline. The `agemon-design-minimal` and `agemon-design-dashboard` variants no longer lock Inter, Geist or IBM Plex.
- `SKILL.md` stack detection now reads Tailwind v4 `@theme` blocks, treats `tailwind.config.*` as live only when `@config` loads it, never reads tokens from built CSS, and adds `components.json` and CSS variables as signals; `DESIGN.md` is read when present and the project's code wins on current values.
- Added an `## Untrusted content` section to `SKILL.md` covering repository files, `DESIGN.md` files, fetched pages, Figma text, PDFs, SVGs and CSS comments, and added a lint rule that requires it for this skill.
- `references/dashboard.md` now describes `heuristics.md` as Cleveland-McGill and Hick's Law checks, since it no longer has PASS/FAIL.
- Also removed the remaining scoring language: the "scored methodology" reference in `references/principles-catalog.md`, the detector rule IDs in `references/typography.md` and `references/dataviz.md`, the "ship it" verdict in `references/review.md`, and the model-judged binary gate in `references/loops.md` (a stop condition is now an objective check or a severity-finding count). Reviews state what was checked and never give a ship or no-ship ruling.
- Reworded four lines that read as things to copy: the default landing signature bet in `references/recipe-landing.md`, "Sparklines on every metric card" in `references/principles-catalog.md`, the generic "FIG" labels in `references/inspiration.md`, and the wording about teal being cool in `references/themes.md`.
