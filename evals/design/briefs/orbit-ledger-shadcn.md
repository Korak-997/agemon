# Brief: Orbit Ledger (repo with stock shadcn/ui)

This repo uses shadcn/ui with its default theme. Build an "Invoices" screen for Orbit Ledger, a
bookkeeping tool for freelancers: a table of invoices with status, amount and due date, a
summary strip above it (outstanding, overdue, paid this month) and an empty state.

Build it as `invoices.html` at the repo root, in static HTML and CSS that opens directly in a browser
with no build step. Use the tokens already in `src/app/globals.css`.
