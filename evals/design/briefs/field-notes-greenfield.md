# Brief: Field Notes (greenfield, no repo conventions)

Build a single-page marketing site for Field Notes, a small paper-notebook subscription for
field biologists. The folder is empty, so choose your own stack. Static HTML with CSS is fine.

The page needs a hero with a clear call to action, a three-step "how it works" section, a
pricing block with two plans, and a footer. The audience is working scientists, not hobbyists.
